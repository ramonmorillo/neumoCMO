# Guía editorial

- **No inventar**: solo se describen funcionalidades comprobadas en el repositorio de cada herramienta. Si no se puede verificar, no se incluye.
- **Trazabilidad**: cada herramienta declara `source` (repositorio) y `evidence` (origen de su URL pública).
- **Sin algoritmos clínicos nuevos**: neumoCMO no calcula, puntúa ni recomienda; enlaza.
- **Sin datos de pacientes**: ningún ejemplo, captura ni texto debe contener datos reales.
- **Sin logotipos institucionales** (SEFH, hospitales, etc.) sin autorización expresa. Las referencias a instituciones son textuales y enlazan a la fuente oficial.
- **Clasificación CMO**: es una propuesta editorial de orientación. Cualquier cambio debe consensuarse con el responsable metodológico.
- **Funcionalidades futuras**: se presentan siempre como «en diseño», nunca como disponibles.
- **Idioma**: español, registro profesional, sin promesas de beneficio clínico.
